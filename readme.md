# Текстовый RPG-боец на Go

Консольная игра, в которой герой сражается с монстром в пошаговом режиме.  

---

## Геймплей

- Герой и монстр поочерёдно атакуют друг друга
- У каждого персонажа есть здоровье, сила, защита и оружие
- Можно использовать предметы из инвентаря для лечения
- Бой идёт до смерти одного из участников

---

## Архитектура

### Основные структуры:
- `Character` — персонаж (HP, сила, защита, оружие, инвентарь)
- `Weapon` — оружие (урон, прочность)
- `Item` — предмет (название, эффект, количество)
- `GameConfig` — настройки баланса (коэффициенты силы, защиты, крита)

### Ключевые методы:
- `Attack(target)` — атака с учётом силы и оружия
- `TakeDamage(damage)` — получение урона с учётом защиты
- `UseItem(itemName)` — использование предмета
- `IsAlive()` — проверка здоровья

### Конкурентность:
- `sync.Mutex` защищает здоровье, оружие и инвентарь от гонок данных
